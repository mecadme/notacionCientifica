# Laboratorio Virtual · Notación Científica y Conversión de Unidades

Laboratorio virtual interactivo de Física para nivel Bachillerato. Permite practicar notación científica y conversión de unidades del Sistema Internacional (SI) directamente en el navegador, sin instalaciones ni dependencias externas.

## Características

- **Decimal ↔ Notación científica**: convierte cualquier número a notación científica normalizada (1 ≤ |a| < 10) y viceversa, con pasos detallados del proceso.
- **Operaciones científicas**: multiplica o divide dos cantidades expresadas en notación científica; normaliza automáticamente el resultado.
- **Conversor de unidades**: convierte entre unidades de longitud, masa, tiempo y volumen usando factores de conversión respecto a la unidad base del SI.
- **Tabla de datos de sesión**: cada cálculo se registra automáticamente en una tabla descargable que sirve como bitácora del laboratorio.
- **Contenido teórico integrado**: introducción, fórmulas, preguntas de análisis, conclusiones y referencias APA 7.

## Tecnologías

HTML5 · CSS3 · JavaScript puro (sin librerías externas)

## Estructura del proyecto

```
notacionCientifica/
├── index.html   # Estructura y contenido de la página
├── style.css    # Estilos y diseño visual
└── script.js    # Lógica matemática e interactividad
```

## Uso

Abre `index.html` directamente en el navegador; no requiere servidor web ni instalación.

1. Lee la introducción teórica y las fórmulas.
2. Usa las tres pestañas de la simulación para realizar cálculos.
3. Revisa la tabla de datos para ver el historial de la sesión.
4. Responde las preguntas de análisis con base en tus resultados.

Tiempo estimado: 30 a 45 minutos.
